1. In a repair order created by a sale order of repair mode, add a part or a
   service. Below the limit it is applied and reaches the sale order; above it
   shows as *Awaiting Approval* and the salesperson gets an activity.
2. A manager approves it internally (with a note) or the pending items are
   refused (a note is required for mandatory items).
3. The repair order cannot be finished while items are pending.
